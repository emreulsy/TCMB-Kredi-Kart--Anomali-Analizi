# TCMB Credit Card Spending Analysis System

A Python-based analysis system that processes weekly credit card spending data (2018–2025) from the Central Bank of the Republic of Turkey's (TCMB) Electronic Data Delivery System (EVDS) to generate reports on consumer trends, detect statistical anomalies, and analyze post-pandemic behavioral shifts.

The project's core goal is to go beyond surface-level observations (e.g. "airline spending dropped during the pandemic") and surface overlooked insights, statistical anomalies, and lasting structural breaks in consumer behavior — such as the 2018 currency crisis and the 2020 pandemic.

## Key Features

The system reads a manually downloaded `data/veri.csv` file and dynamically recognizes 30+ sectors. It automatically runs the following 3-layer analysis and saves results to the `output/` folder:

### Layer 1: Data Processing and Base Reports
The system processes raw weekly data and generates baseline trend reports:
1. **`rapor_haftalik_toplamlar.csv`**: Weekly nominal spending totals by sector.
2. **`rapor_aylik_toplamlar.csv`**: Weekly data aggregated into monthly totals.
3. **`rapor_buyume_istatistikleri.csv`**: Cumulative growth statistics by sector from 2018 to 2025.

### Layer 2: Behavioral Analysis Reports
Produces "share" analyses to filter out noise like inflation and reveal real consumer behavior:
4. **`rapor_haftalik_paylar.csv`**: Each sector's percentage share of total weekly spending.
5. **`rapor_aylik_paylar.csv`**: Monthly spending shares for long-term trend analysis.
6. **`rapor_haftalik_yillik_buyume.csv`**: Seasonally-adjusted year-over-year percentage growth (compared to the same week in the prior year).

### Layer 3: Advanced Analysis and Insight Reports
Includes two second-level analysis scripts aimed at answering the "why":

7. **`rapor_anomaliler.csv` (Anomaly Detection):**
   * Generated by the `anomali_analizi.py` script.
   * Calculates each sector's "normal" growth corridor and lists "positive/negative shocks" that fall outside it (e.g. panic buying during the 2018 currency crisis), along with their dates.

8. **`rapor_korelasyon_...csv` (Correlation Analysis):**
   * Generated by the `korelasyon_analizi.py` script.
   * Maps inter-sector relationships for the **pre-pandemic period (2018–19)** and the **"new normal" period (2022–25)**.
   * Reveals how relationships between sectors — such as "restaurants vs. grocery" or "telecom vs. e-commerce" — *permanently* shifted due to the pandemic (substitution effects, behavioral breaks).

## Tech Stack

* **Python 3.x**
* **Pandas:** Core library for data processing, cleaning, analysis, and reporting.

## How to Use

1. **Set up a virtual environment:**
   ```bash
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. **Install requirements:**
   ```bash
   pip install -r requirements.txt
   ```
   *(Note: if you don't have a `requirements.txt`, generate one with `pip freeze > requirements.txt`, or install manually with `pip install pandas`.)*

3. **Download the data:**
   * Go to the TCMB EVDS website.
   * Select all `TP.KKHARTUT...` series you need, at weekly frequency, from 2018-01-01 to present.
   * Download the data in **CSV** format.
   * Rename the downloaded file to `veri.csv` and move it into the `/data` folder.

4. **Run the main reports:**
   ```powershell
   .\.venv\Scripts\python.exe main.py
   ```
   *(This generates the first 6 reports in the `output/` folder.)*

5. **Run the advanced analyses:**
   ```powershell
   # To generate the anomaly report:
   .\.venv\Scripts\python.exe anomali_analizi.py

   # To generate the correlation reports:
   .\.venv\Scripts\python.exe korelasyon_analizi.py
   ```

6. **Review the results:**
   All 8+ analytical reports will be ready in the `output/` folder.
